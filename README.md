# 🏥 ShivanyaRx AI - Frontend Web App 🌟

Welcome to the frontend application for **ShivanyaRx **! This is the user interface where pharmacists and staff can log in, view insights, manage inventory, and monitor patients.

This project is built with **React**, **TypeScript**, and **Vite**, offering a lightning-fast development experience! ⚡

---

## 🚀 Quick Start for Beginners

Follow these simple steps to get the project running on your local machine:

### 1️⃣ Prerequisites
First, ensure you have **Node.js** installed on your computer. You can download it from [nodejs.org](https://nodejs.org/).

### 2️⃣ Install Dependencies
Open your terminal (or command prompt), navigate to this folder, and run:
```bash
# This installs all the required packages for the project
npm install
```

### 3️⃣ Run the App Locally
Once the installation is done, you can start the development server:
```bash
# This will start the app
npm run dev
```
🎉 **That's it!** The terminal will show a local URL (usually `http://localhost:5173/`). Click or copy-paste it into your browser to see the app! The app will automatically reload whenever you make changes to the code.

## 📂 Project Structure Guide

Here is a quick overview of what is inside this repository so you don't get lost:

* 📁 **`src/`** 👉 **This is where you will write most of your code!**
  * `pages/` - The main screens (like Dashboard, Orders, Patients, etc.)
  * `components/` - Smaller reusable UI parts (like Buttons, Cards, Modals, Navbar)
  * `assets/` - Images, icons, and static files go here
* 📁 **`public/`** 👉 Publicly accessible files (like `favicon.ico`)
* 📄 **`package.json`** 👉 Contains app information and the list of dependencies installed
* 📄 **`vite.config.ts`** 👉 Vite configuration file

## 🛠️ Helpful Commands

* `npm run dev` - Starts the app for development with Hot Reload
* `npm run build` - Packages the app ready for production deployment
* `npm run preview` - Runs the production build locally to test it
* `npm run lint` - Checks the code for any styling or syntax errors
